# Portfolio uploads

The deployed portfolio uses these public files:

- `profile.jfif` — profile image used in the hero
- `Nikku-Kumar-Resume.pdf` — downloadable resume linked from the hero

Vite serves them from `/uploads/` in development and `/portfolio/uploads/` on GitHub Pages. Everything in `public` is publicly accessible, so this folder must not contain passwords, private documents, or other sensitive files.
